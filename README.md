# VaaniRakshak-Real-Time-Regional-Language-Voice-Scam-Voice-Clone-Detection-for-Live-Phone-Calls
Unlike caller-ID or SMS-based spam filters, VaaniRakshak listens to what is actually being said and how it is being said, in real time, and is designed to run with on-device or edge processing so that sensitive call audio never has to leave the user's phone.
